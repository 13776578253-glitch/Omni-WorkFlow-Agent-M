# 1 单元测试

本项目中的单元测试是指：针对最小可测试代码单元开展的测试，主要验证函数、接口封装方法、数据转换逻辑和工具方法是否正确。单元测试强调隔离外部依赖，使用 mock 数据替代真实网络请求或真实后端服务。本项目单元测试主要采用前端 `Jest` 完成。

## 1.1 核心模块汇总

| 序号 | 模块名称 | 单元测试对象 | 主要测试内容 | 测试结果 |
|---|---|---|---|---|
| 1 | 认证模块 | `auth-api.ts` | 响应解析、请求体映射、异常抛出 | 通过 |
| 2 | 用户偏好模块 | `personal-api.ts` | 偏好配置读取、保存、错误处理 | 通过 |
| 3 | 历史记录模块 | `history-api.ts` | 会话列表获取、创建、修改、删除 | 通过 |
| 4 | Portal 模块 | `home-component-api.ts` | 月历查询、单日更新、单日删除 | 通过 |
| 5 | Workflow 模块 | `workflow-api.ts`、`Workflow_audio_utils.ts` | 字段兼容、转写拼装、上传映射、音频识别 | 通过 |
