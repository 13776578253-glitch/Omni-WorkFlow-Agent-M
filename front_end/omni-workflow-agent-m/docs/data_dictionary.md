## 4.1.3 数据词典

为统一系统开发、测试与文档描述中的数据概念，本项目仅保留与核心业务流程直接相关的数据项，并对其含义进行统一说明。数据词典不用于描述数据库结构，而用于明确系统中关键数据“是什么、表示什么、如何理解”。

| 数据项 | 含义说明 | 取值/格式说明 |
| --- | --- | --- |
| 用户ID | 系统中用于唯一标识用户的信息 | 字符串 |
| 会话ID | 标识一次完整工作流任务处理过程的唯一编号 | 字符串 |
| 消息块ID | 标识工作流中单条消息或单个内容块的唯一编号 | 字符串 |
| 消息角色 | 标识消息内容的来源身份 | `user / ai` |
| 消息内容 | 用户输入或系统生成的文本内容 | 文本 |
| 文件引用 | 文件上传后在系统中的访问或定位信息 | 路径或 URL |
| 音频资源ID | 系统中用于标识音频资源的唯一编号 | 字符串 |
| 转写文本 | 语音识别后得到的文本结果 | 文本 |
| 任务状态 | 标识任务当前执行进度 | `pending / processing / completed / failed` |
| 会话标题 | 历史记录中显示的会话名称 | 文本 |
| 预设模式 | 用户选择的输出风格或处理模式 | `custom / concise / formal` |
| 快捷提示词 | 与快捷操作绑定的提示内容 | 文本 |
| 长期记忆 | 用户长期偏好或固定要求的文本描述 | 文本 |
| 工作流模式 | 标识当前工作流界面的处理状态 | `welcome / document / recording` |
